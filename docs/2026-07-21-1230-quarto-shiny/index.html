핵심 메시지

분석 코드는 계산을 맡고, Quarto는 설명을 붙이며, Shiny는 사용자가 값을 바꿔 보게 합니다.

Quarto

  • 분석 과정과 결과를 문서로 엮습니다.
  • 같은 qmd 파일에서 보고서, 슬라이드, HTML을 만들 수 있습니다.
  • 코드, 표, 그림, 해석을 한 흐름으로 관리합니다.

Shiny

  • 사용자가 조건을 고르면 결과가 바로 바뀝니다.
  • 필터, 표, 그래프, 모델 결과를 웹 화면으로 보여줍니다.
  • 반복 질문이 많은 분석을 공유하기 좋습니다.

bootcamp-analysis/

위쪽 YAML은 문서 설정, 본문은 Markdown입니다. 실행할 R 코드 블록은 시작 줄에 {r}을 붙여 씁니다.

Markdown으로 슬라이드 쓰기

  • #은 큰 제목, ##은 새 슬라이드 제목입니다.
  • 불릿은 짧게 씁니다.
  • 표는 비교가 필요할 때 씁니다.
  • 그림은 한 슬라이드에 하나씩 크게 배치합니다.
  • 발표 슬라이드는 문장보다 구조가 먼저 보이게 만듭니다.

Shiny의 기본 구조

library(shiny)

ui <- fluidPage(
  titlePanel("분석웹"),
  sidebarLayout(
    sidebarPanel(
      selectInput("group", "그룹", choices = c("A", "B"))
    ),
    mainPanel(
      plotOutput("plot"),
      tableOutput("table")
    )
  )
)
server <- function(input, output, session) {
  output$plot <- renderPlot({
    # input$group에 맞춘 그림
  })

  output$table <- renderTable({
    # input$group에 맞춘 표
  })
}

shinyApp(ui, server)

반응형 흐름

  1. 사용자가 화면에서 값을 고릅니다.
  2. input$변수명이 바뀝니다.
  3. reactive() 계산이 다시 실행됩니다.
  4. renderPlot(), renderTable() 같은 출력 함수가 화면을 갱신합니다.

Shiny에서는 값이 바뀔 때마다 다시 계산해야 하는 부분과 한 번만 계산해도 되는 부분을 나누어 생각합니다.

간단한 Shiny 예시

  • selectInput()으로 실린더 수를 고릅니다.
  • reactive()에서 선택된 값에 맞춰 데이터를 거릅니다.
  • 같은 데이터를 그림과 표에 함께 씁니다.

전체 예시는 code/2026-07-21-1230-quarto-shiny.R에서 확인합니다.

filtered <- reactive({
  mtcars |> filter(cyl == as.numeric(input$cyl))
})

output$scatter <- renderPlot({
  ggplot(filtered(), aes(wt, mpg)) +
    geom_point(size = 3)
})

output$summary <- renderTable({
  filtered() |>
    summarise(
      n = n(),
      mean_mpg = mean(mpg)
    )
})
