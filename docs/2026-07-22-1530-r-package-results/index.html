오늘의 목표

01. ATLAS에서 만든 estimation 분석 패키지를 다운로드합니다.
02. RStudio 서버에서 패키지 구조와 실행 코드를 확인합니다.
03. 제공되는 코드를 단계별로 실행하여 결과 파일을 생성합니다.
04. 생성된 결과 zip을 CDM META Analysis에서 확인합니다.

목표: ATLAS 설계물이 실제 R 분석 결과로 이어지는 흐름을 알수있게 도와줍니다.

핵심 개념

이번 실습의 핵심은 ATLAS에서 만든 분석 설계를 R에서 실행 가능한 결과로 바꾸는 과정입니다.

Background Info

  • ATLAS에서는 어떤 환자를 비교할지, 어떤 outcome을 볼지, 어떤 분석 방법을 쓸지 정의합니다.
  • 이 설정은 아직 결과가 아니라, 분석을 실행하기 위한 설계도입니다.
  • Study Package는 이 설계도를 R 코드, SQL, 설정 파일로 묶어 내려받은 실행 패키지입니다.
  • RStudio에서는 이 패키지를 CDM 데이터베이스에 연결해 cohort 생성, 분석 실행, 결과 저장까지 수행합니다.
  • 최종 결과는 output/ 폴더와 Results_*.zip 파일로 확인합니다.

실습 시작: Study Package 다운로드

1. Estimation 메뉴 클릭
ATLAS에서 실행할 분석 화면으로 이동합니다.

2. 분석 이름 클릭
다운로드할 study package의 분석 항목을 선택합니다.

3. Utilities → Download
Package name을 입력한 뒤 zip 파일을 다운로드합니다.

다운로드된 패키지 구조 확인

RStudio Files 창에서 압축 해제된 package 폴더를 확인합니다.

  • .Rproj: RStudio 프로젝트 파일
  • DESCRIPTION, NAMESPACE: R package 기본 정보
  • R/, man/: 패키지 함수와 문서
  • extras/: 실행용 스크립트 위치
  • inst/, HydraConfig.json: ATLAS 분석 설정
  • README.md: 실행 안내
  • renv/, renv.lock: 패키지 환경 재현

코드 실행 및 결과 확인

실행 방법
가져온 code/2026-07-22-1530-cdm-rpackage-run.R 코드를 단계별로 실행합니다.
커서가 있는 줄 또는 선택한 코드 블록이 Console에서 실행됩니다.

실행 흐름

  1. renv::restore() : 필요한 패키지 환경 복원
  2. install.packages(“.”, …) : study package 설치
  3. library(TESTPLZ) : 패키지 로드 및 dependency 확인
  4. outputFolder, maxCores 등 실행 옵션 설정
  5. connectionDetails : CDM database 연결 정보 설정
  6. cdmDatabaseSchema, cohortDatabaseSchema 설정
  7. execute(…) : cohort 생성, 분석 실행, 결과 패키징
  8. resultsZipFile : 생성된 결과 zip 파일 경로 확인
