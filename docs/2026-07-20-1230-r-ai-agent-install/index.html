AI 코딩 에이전트란?

구분 일반 챗봇 Codex
작업 방식 답변을 보고 사람이 복사 파일을 읽고 직접 수정

핵심은 코드 제안이 아니라 연구 폴더 안에서 파일을 만들고, 실행하고, 고치는 작업 흐름입니다.

의학연구에서 쓸 곳

  • 데이터 읽기와 변수 정리
  • 결측, 이상치, 범주형 변수 처리
  • Table 1, 회귀분석, 생존분석
  • 그림과 표를 논문용 파일로 저장
  • Statistical Analysis 문단 초안 작성
  • 결과 재현용 코드 정리

수업에서 쓰는 방식

RStudio는 분석 결과를 확인하는 작업대입니다. Codex는 터미널에서 코드 작성, 실행, 수정, 정리를 맡깁니다.

연구 폴더
├── data/        # 원자료 또는 예시자료
├── code/        # R 코드
├── results/     # 표, 그림, 모델 결과
├── docs/        # 보고서, 슬라이드
└── AGENTS.md    # Codex에게 반복해서 지킬 규칙

설치 전 확인

  • Git이 설치되어 있어야 합니다.
  • R과 RStudio가 설치되어 있으면 좋습니다.
  • 터미널을 열 수 있어야 합니다.
  • 수업용 API key는 당일 안내에 따라 입력합니다.

Mac: 터미널 열기

  1. Command + Space를 누릅니다.
  2. Terminal을 검색해 실행합니다.
  3. 실습 폴더로 이동합니다.
mkdir -p ~/Documents/bootcamp-r
cd ~/Documents/bootcamp-r

Mac: Git과 R 확인

git --version
Rscript --version

git 명령이 없다고 나오면 macOS가 Xcode Command Line Tools 설치를 안내합니다. 설치 후 터미널을 다시 열면 됩니다.

Mac: Codex 설치

curl -fsSL https://chatgpt.com/codex/install.sh | sh

설치 후 터미널을 닫았다가 다시 열고 확인합니다.

codex

Windows: 권장 경로

Windows에서는 두 가지 경로가 있습니다.

  • Codex 앱: 화면 중심으로 쓰기 쉽습니다.
  • WSL2 터미널: R, Git, 패키지 설치가 수업 실습과 잘 맞습니다.

이번 수업의 터미널 실습은 WSL2 기준으로 맞춥니다.

Windows: WSL2 설치

PowerShell을 관리자 권한으로 열고 실행합니다.

wsl --install

설치가 끝나면 재부팅하고 Ubuntu를 엽니다.

wsl

Windows: WSL2에서 기본 도구 설치

Ubuntu 터미널에서 실행합니다.

sudo apt update
sudo apt install -y git curl r-base
git --version
Rscript --version

Windows: WSL2에서 Codex 설치

curl -fsSL https://chatgpt.com/codex/install.sh | sh

설치 후 Ubuntu 터미널을 다시 열고 실행합니다.

codex

Windows: Codex 앱을 쓰는 경우

PowerShell에서 앱 설치가 필요하면 다음 명령을 사용할 수 있습니다.

winget install Codex -s msstore

앱은 프로젝트를 살펴보고 병렬 작업을 관리하기 편합니다. 터미널 실습은 WSL2에서 맞춥니다.

인증 방식

Codex는 두 가지 방식으로 로그인할 수 있습니다.

방식 쓰는 경우
ChatGPT 로그인 개인 또는 기관 ChatGPT 계정으로 실습할 때
API key 수업용 key나 OpenAI Platform 과금 계정을 쓸 때 
codex login

API key 입력

API key는 수업 당일 안내합니다. 슬라이드와 저장소에는 실제 key를 적지 않습니다.

export OPENAI_API_KEY=""

Windows WSL2에서도 같은 방식으로 입력합니다.

export OPENAI_API_KEY=""

R 패키지 설치

R 콘솔이나 RStudio에서 실행합니다.

install.packages(c(
  "data.table", "magrittr", "survival", "jskm", "jstable",
  "flextable", "officer", "rvg", "ggplot2", "openxlsx2"
))

실습 폴더 만들기

mkdir -p bootcamp-r/{data,code,results,docs}
cd bootcamp-r

Codex는 현재 폴더를 기준으로 파일을 읽고 수정합니다. 실습 전에는 반드시 원하는 연구 폴더로 이동합니다.

AGENTS.md 만들기

AGENTS.md는 Codex가 프로젝트 안에서 계속 참고할 규칙입니다.

# 분석 규칙

- R 코드는 code/ 폴더에 저장한다.
- 결과물은 results/ 폴더에 저장한다.
- 표는 xlsx, 그림은 pptx로 저장한다.
- 분석 결과는 재현 가능하도록 주석을 남긴다.

승인과 보안

  • Codex가 파일을 수정하거나 명령을 실행하기 전 내용을 확인합니다.
  • 네트워크 접근이나 폴더 밖 작업은 승인 요청이 뜰 수 있습니다.
  • API key, 개인정보, 원자료는 채팅에 그대로 붙여넣지 않습니다.
  • 결과가 맞는지는 사람이 최종 확인합니다.
