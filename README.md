# 2026 여름 디지털 헬스케어 부트캠프

연세의료원 2026 여름 디지털 헬스케어 부트캠프 강의자료 저장소입니다. 수업 중에는 이 README를 목차로 쓰고, 김진섭 강의는 항목에서 바로 슬라이드로 이동할 수 있게 정리합니다. 강의록과 렌더링된 HTML은 `docs/`, 실습 코드는 `code/`에 둡니다.

## 목표

기본반은 R과 AI agent로 의학연구 데이터를 정리하고, 분석 결과를 표, 그림, 문서, 슬라이드로 남기는 흐름을 다룹니다. 심화반은 CDW/CDM과 MIMIC 기반 실습을 거쳐 팀별 프로젝트와 발표로 이어집니다.

## 자료 구성

- `quarto-style/`: Quarto revealjs 슬라이드 디자인 가이드
- `docs/`: 차시별 qmd 파일과 렌더링된 HTML 슬라이드
- `code/`: 차시별 실습 코드
- `2026 부트캠프 커리큘럼 및 일정표.xlsx`: 원본 일정표

일정표에 기존 URL이 적힌 항목 중 원본이 확인된 자료는 revealjs로 변환해 `docs/`에 넣었습니다. 나머지 김진섭 강의는 `docs/<강의>/index.html` 자리표시자에 연결해 두었습니다.

## 준비사항

1. [Posit Cloud](https://posit.cloud)에 가입하거나 개인 노트북에 RStudio를 설치합니다.
2. R 데이터분석 참고자료: [r-skku-biohrs](https://github.com/jinseob2kim/r-skku-biohrs)
3. CDM 참고자료: [The Book of OHDSI Korea](https://ohdsi-korea.github.io/TheBookOfOhdsiKorea/)
